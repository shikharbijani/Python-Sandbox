# Minecraft Inventory Manager
These are the projects I built while learning Python data structures and program design.
The project simulates a simple Minecraft inventory system where resources can be gathered, items can be crafted, and the inventory updates based on the player's actions.

## minecraft_v1
The first version of the project.
This version introduced the basic inventory system using Python dictionaries. It allowed the user to gather resources, craft tools, and view their inventory through a menu-driven interface.
Concepts practiced:
- Dictionaries
- Lists
- Loops
- Functions
- Match-case statements
- Basic program flow

## minecraft_v2
Built on top of `minecraft_v1`.
This version improves the overall structure and expands the project with new features.
Improvements include:
- Cleaner and more organized code
- Smelting system
- Achievement system
- Better inventory management
- Improved menu structure
- More resources and crafting options

This version helped me practice writing larger programs and managing a changing program state using Python data structures.
