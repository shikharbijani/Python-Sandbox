# F1 Hub API 🏎️
A command-line application built while learning how to work with APIs in Python.
The program allows users to search for Formula 1 driver information using an online API and also includes a random driver feature.

## Purpose
This project was created to practice making HTTP requests, working with JSON data, and handling responses from an external API.

## Versions

### f1_hub_v1
The first version of the project.
Features:
- Search for a Formula 1 driver by name
- Retrieve driver information from an online API
- Display API results in the terminal

### f1_hub_v2
Built on top of **f1_hub_v1**.
Improvements include:
- Random driver generator
- Better program organization
- Improved error handling
- Cleaner menu-driven interface

## Concepts Practiced
- APIs
- HTTP requests (`requests`)
- JSON data
- Error handling (`try` / `except`)
- Functions
- Loops
- Menu-driven program design
- Random module
