# Python Sandbox

Welcome to my Python Sandbox!

This repository contains projects I have built while learning Python. It serves as a collection of my practice projects, experiments, and progress as I continue developing my programming skills.

## About

I am currently learning Python through **CS50's Introduction to Programming with Python** by Harvard University.

The goal of this repository is to:

* Document my learning journey.
* Practice newly learned Python concepts through projects.
* Track how my coding style, project structure, and problem-solving skills improve over time.
* Build a portfolio of projects before moving deeper into Data Science and AI.

## Projects

### F1 Hub API

A simple Formula 1 driver search application built while learning how to work with APIs, JSON data, HTTP requests, and external libraries.

### Minecraft Inventory Manager

A menu-driven inventory system inspired by Minecraft. This project helped me practice dictionaries, lists, functions, program logic, and managing program state.

### Study Logger

A CSV-based application for recording and viewing study sessions. This project was built while learning file handling, CSV files, input validation, regular expressions, functions, and basic program structure.

### Library Management System

A simple library management project built while learning Object-Oriented Programming. It uses classes and objects to represent books and a library, allowing books to be added, viewed, borrowed, and returned.
