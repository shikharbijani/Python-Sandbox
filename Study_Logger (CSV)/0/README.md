# Study Logger 
A simple command-line application built while learning file handling in Python.
The program allows users to record study sessions in a CSV file and view previously logged sessions.

## Purpose
This project was created to practice working with files and CSV data in Python. It focuses on reading from and writing to files while maintaining a simple, menu-driven interface.

## Features
- Add a new study session
- Store study sessions in a CSV file
- View all previously recorded sessions
- Simple command-line menu

## Concepts Practiced
- File handling (`open`)
- Context managers (`with`)
- CSV module
- Reading and writing CSV files
- Functions
- Loops
- Basic menu-driven program design
